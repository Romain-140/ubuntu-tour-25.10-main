# Ubuntu Tour (25.10)
Ubuntu Tour for version 25.10\
Inspired by [malisipi](https://github.com/malisipi/ubuntu-tour)'s project, but independant.

## Features
* GRUB like start menu
* Ubuntu 25 login page
* Custom apps
